
# 🍳 Dapur Sultan Tycoon

**Dari Warung Kecil Menuju Sultan Kuliner!**

Dapur Sultan Tycoon adalah game simulasi memasak dan bisnis restoran. Mulailah dari warung sederhana, layani pelanggan, kumpulkan uang, dan kembangkan restoranmu menjadi bisnis kuliner yang sukses!

## 🎮 Fitur Game
- 🍜 Memasak berbagai hidangan.
- 💰 Mendapatkan uang dari pelanggan.
- 🏪 Mengembangkan dan meningkatkan restoran.
- 👨‍🍳 Mengelola koki dan staf.
- 📈 Membuka menu dan peningkatan baru.

## 🎯 Tujuan
Bangun restoran dari usaha kecil hingga menjadi restoran terkenal dan jadilah sultan kuliner!

## 📱 Platform
- Android (jika sudah berhasil dibuat APK).
